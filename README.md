# GPT From Scratch

Building a character-level GPT language model from scratch using Python and PyTorch, following Andrej Karpathy's *Let's build GPT* lecture.

## Learning Progress

- [x] Character-level tokenization
- [x] Dataset encoding and train/validation split
- [x] Data batching
- [x] Bigram language model
- [ ] Self-attention
- [ ] Multi-head attention
- [ ] Transformer architecture
- [x] Autoregressive text generation (untrained Bigram)
- [ ] Model training and optimization

## Technologies

Python, PyTorch, Google Colab
